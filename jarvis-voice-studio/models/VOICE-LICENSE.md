# Neural voice (download separately)

- Files: `pt_BR-faber-medium.onnx` and `pt_BR-faber-medium.onnx.json`.
- Source: [rhasspy/piper-voices — Faber medium, pt_BR](https://huggingface.co/rhasspy/piper-voices/tree/main/pt/pt_BR/faber/medium).
- The model card lists the language `pt_BR`, a single speaker, 22,050 Hz sampling, and a CC0 license for the voice dataset; the model file is distributed in the voices repository under the MIT license. The model was fine-tuned from Lessac medium.
- Expected SHA-256 of the ONNX: `858555e3a064209c57088fe6bd70c4c3dc54d03eaa00c45d5ecaf43a33f95aa7`.
- Piper runtime: `piper-tts` package 1.8.0, GPL-3.0; the full license text ships with the `piper-tts` package installed via pip.

"JARVIS — Official Voice" is the name of a usage profile that selects this existing Brazilian male voice with moderate parameters. It is not a clone, nor a model trained to imitate a specific person.
